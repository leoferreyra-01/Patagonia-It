# Patagonia-It

NestJS standalone API for the technical challenge.

## Requirements

- Node 24

## Run locally

1. Install dependencies:

```bash
npm install
```

2. Start in dev mode:

```bash
npm run start:dev
```

## API URLs

- API base URL: http://localhost:3000/api
- Health endpoint: http://localhost:3000/api/health
- Swagger UI: http://localhost:3000/docs

## Tests

```bash
npm test
```
